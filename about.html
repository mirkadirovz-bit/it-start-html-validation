О проекте и проверке HTML

Этот сайт помогает познакомиться с IT-профессиями и показывает настройку автоматической проверки разметки.

Что использовано

  • HTML для структуры страниц.
  • CSS для оформления и адаптации к экрану.
  • Локальное SVG-изображение с текстовым описанием.
  • html-validate для проверки двух страниц.
  • GitHub Actions для запуска проверки после изменений.

Как выполняется проверка

  1. Изменения отправляются в ветку main или в Pull Request к main.
  2. GitHub Actions получает файлы и настраивает Node.js.
  3. Устанавливается html-validate версии 10.5.0.
  4. Команда npm run validate проверяет index.html и about.html.
  5. Ошибки исправляются, затем проверка запускается повторно.

Правила проверки: документация html-validate.

Качество разметки

На страницах указаны язык и кодировка, соблюдена иерархия заголовков, у изображения есть alt, а у таблицы — подпись и заголовки. Валидатор проверяет разметку; удобство сайта и внешний вид нужно проверять отдельно.
